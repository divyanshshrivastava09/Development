# Overpowered Creations 

**Overpowered Creations** is a creative agency landing page built using HTML and CSS. It features bold typography, vibrant colors, modern layouts, and striking visuals to showcase creativity, innovation, and unique digital design.

## Features

- Bold, oversized typography with uppercase headings.
- Bright yellow background with a teal navigation bar.
- Navigation links for About Us, Projects, Services, and Contact.
- CSS Grid layout to organize headings, images, and text.
- Image frames with rounded corners and cropped images.
- Responsive viewport configuration for different screen sizes.
- Creative agency tagline highlighting innovation and design.

## Technologies Used

- **HTML5** — For webpage structure and content.
- **CSS3** — For styling, layouts, spacing, colors, and typography.

## HTML Tags Used

| HTML Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares the document as HTML5. |
| `<html>` | Root element of the webpage. |
| `<head>` | Contains metadata and the page title. |
| `<meta>` | Defines character encoding and viewport settings. |
| `<title>` | Sets the browser tab title. |
| `<link>` | Connects the external CSS stylesheet. |
| `<body>` | Contains the visible webpage content. |
| `<main>` | Represents the main content of the page. |
| `<nav>` | Creates the navigation section. |
| `<h1>` | Displays the main headings. |
| `<h2>` | Displays the welcome heading. |
| `<a>` | Creates navigation links. |
| `<section>` | Groups related webpage content. |
| `<div>` | Groups elements for layout and styling. |
| `<p>` | Displays the agency description. |
| `<img>` | Displays images with alternative text. |

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure `index.html` is linked to `style.css`.
4. Open `index.html` in your browser or use the Live Server extension in VS Code.

## Project Goal

The goal of this project is to practice HTML fundamentals, CSS styling, Flexbox, CSS Grid, typography, and image positioning while creating a visually engaging creative agency landing page.
